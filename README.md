# Home Credit LAP Voice Agent Lab

A standalone, dependency-free Node.js demo for a Home Credit Loan Against Property (LAP) qualification call. It pairs a deterministic conversation/state machine with a local browser interface, automated scenarios, a paste-ready system prompt, and a Retell AI adapter guide.

## Run locally on Windows

Install Node.js 18 or newer, open PowerShell in this folder, then run:

```powershell
npm test
npm start
```

Open **http://127.0.0.1:3000**. No `npm install` is needed: the app and tests use only Node.js built-ins. To use another port:

```powershell
$env:PORT = "3100"
npm start
```

The demo binds to loopback only. Setup values, customer messages, and transcripts stay in browser memory and the local Node process; they are not written to disk or sent to an AI service. Restarting the server clears in-memory sessions. This is a local prototype, not a production customer-data store.

## What is included

- **Deterministic call core** (`src/conversation.js`): customer identity check, busy/callback, offer and consent, all seven eligibility fields, out-of-order capture, corrections, explicit disqualification, the ₹75-lakh cap branch, transfer-specialist routing, and a gated senior-expert handoff.
- **Local browser demo** (`public/`): editable session variables, transcript, one-click customer utterance examples, and a live seven-field checklist.
- **HTTP API** (`server.js`): local demo sessions and a Retell custom-function endpoint. `GET /api/health` is the readiness check.
- **Prompt and platform setup** (`docs/SYSTEM_PROMPT.md`, `docs/RETELL_SETUP.md`).
- **Mock cases and tests** (`scenarios/scenarios.json`, `test/conversation.test.js`).

All model-sensitive voice responses in the local demo are generated by explicit state transitions rather than a free-form LLM response. The deterministic parser intentionally covers common English/Hindi responses and corrections; it is not a production-grade speech-recognition or language-understanding system. In Retell, use the function-backed flow in the guide so the server remains the qualification source of truth.

## Conversation rules implemented

The first response verifies the named customer. After verification, the agent presents Home Credit's loyalty offer of up to **₹75,00,000** and asks whether the customer wants to continue. The ordered checklist is:

1. Property type (residential, commercial, industrial; agricultural disqualifies).
2. Sole or joint ownership.
3. Original property documents available.
4. Requested amount (₹75,00,000 maximum; ask whether the cap works before continuing).
5. Salaried/self-employed and income received by bank (cash disqualifies).
6. Approximate current property market value.
7. Repayment tenure (3–15 years).

The agent records volunteered answers out of order, keeps the most recent correction, and only asks for missing or ambiguous information. An ineligible answer ends the call politely; an existing property loan or EMI-reduction intent routes to a loan-transfer specialist. The human expert handoff is unreachable until every field is complete and eligible. The agent does not promise approval or quote a rate.

## Local API

Create a session:

```powershell
$session = Invoke-RestMethod -Method Post -Uri http://127.0.0.1:3000/api/sessions `
  -ContentType "application/json" `
  -Body '{"variables":{"customer_name":"Priya Sharma","company_name":"Home Credit","agent_name":"Mira","agent_gender":"female","language_to_speak":"English"}}'
$session
```

Send a customer turn (replace the ID with `$session.session_id`):

```powershell
$id = $session.session_id
Invoke-RestMethod -Method Post -Uri "http://127.0.0.1:3000/api/sessions/$id/turn" `
  -ContentType "application/json" `
  -Body '{"customer_utterance":"Yes, this is Priya Sharma."}'
```

Accepted session variables: `company_name`, `customer_name`, `agent_name`, `agent_gender` (`male`, `female`, or `neutral`), `current_date`, `current_day`, `current_time`, `additional_context_from_rag`, `language_to_speak` (`English` or `Hindi`), and `conversation_history`. Each turn supplies `customer_utterance`. The backend keeps the live transcript separately; injected history is context only and cannot make a checklist field complete.

## External account and recording submission

The local app does **not** create a Retell account, place calls, make a loan offer to a real customer, or generate a public recording/log URL. Follow the manual account, testing, privacy, and public-link steps in [`docs/RETELL_SETUP.md`](docs/RETELL_SETUP.md) with your own authorized Retell account and any required phone number/credentials. Do not upload real customer PII or publish a recording without the required consent and approval.
